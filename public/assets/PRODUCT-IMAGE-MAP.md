# Mohana Leather image library

Product imagery is stored locally in `public/assets/images/mohana/` and mapped to catalog entries in `src/products.ts`. It uses the product and editorial photos supplied for this store. Promotional banners are also included in that folder for future page placements.

The storefront titles, color labels, material notes, and fit copy are matched to each selected image. Collection and home page hero images now use the supplied Mohana Leather photographs rather than the previous stock campaign videos.

The supplied bundle contains many repeated screenshots and only a few matching alternate angles. Product galleries show a single image by default and include an additional view only where the files show the same jacket from another angle. No unrelated jacket or repeated file is used to fill a gallery.

The source screenshots are retained in the project root `Mohana Leather/` folder. The curated public copies have descriptive filenames so they can be maintained without relying on the original numbered filenames.
