# Local campaign videos

All videos are served locally from this directory. Each film is assigned to one hero location only.

| File | Placement | Source |
|---|---|---|
| `home-editorial.mp4` | Home hero | User-supplied `7037869-uhd_4096_2160_25fps.mp4` (local copy, 4096 × 2160, approximately 37.3 MB). Replace this file to change the homepage film. |
| `outerwear-edit.mp4` | Men's collection hero | Pexels footage: [Men Wearing Puffer Jackets](https://www.pexels.com/video/men-wearing-puffer-jackets-7038079/) and [A Low Angle View of a Man Wearing Jacket](https://www.pexels.com/video/a-low-angle-view-of-a-man-wearing-jacket-10133016/). |
| `winter-campaign.mp4` | Women's collection hero | Pexels footage: [Fashionable Woman Wearing a Black Coat](https://www.pexels.com/video/fashionable-woman-wearing-a-black-coat-6535752/). |
| `overcoat-editorial.mp4` | Overcoat collection hero | Locally generated, short overcoat styling loop using the local men's and women's overcoat imagery. |
| `new-arrivals-editorial.mp4` | New Arrivals hero | Locally generated mixed-gender outerwear loop using four local men's and women's product images. |

The two Pexels clips are used under the [Pexels license](https://www.pexels.com/license/). The three locally generated MP4 loops are image-motion edits rather than additional live-action stock footage; replace them if live-action mixed-fashion, overcoat, or new-arrivals campaigns are preferred. All five files are separate and are not reused in other sections.
